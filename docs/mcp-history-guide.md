# MCP履歴

左メニューの **MCP履歴** から、この端末が他端末へ依頼した仕事と、この端末で受け付けた仕事を確認できます。タスクの受付設定は **moyAI Hub → 端末連携** で行います。

## MCP指示とMCP実行

- **MCP指示**: Hubの端末連携を使って、この端末から他端末へ委任したタスクです。相手端末、公開対象、保存済みの状態、停止確認、取得済みの結果を表示します。相手の現在の状態を断定する表示ではありません。
- **MCP実行**: この端末が受け付けたタスクです。Hub経由の受付と、従来の手動配信で受け付けたタスクを含みます。受け取った指示と、この端末で実行した処理の記録を確認できます。

行を選択すると詳細が表示されます。過去の履歴はページを切り替えて確認できます。通常チャットの選択や入力中の文章は変わりません。実行中のタスクは、この画面を開いている間に表示を更新します。

履歴は各端末のローカルデータに保存されています。受付OFF、Hubからの切断、アプリの再起動後も、保存済みの履歴を閲覧できます。指示側で保持するのは、指示側が記録・取得できた内容です。相手端末の全実行ログを暗黙に取り込む機能ではありません。従来のURL・トークンによる手動接続から出した指示は、元の通常チャットのツール履歴で確認します。

## 状態の読み方

実行側の完了と、指示側の結果取得は別の情報です。結果が未取得なら、そのことを表示します。停止要求を送っただけの状態と、停止を確認した状態も区別します。相手が接続不能でも、最後に確認した「実行中」を「停止済み」に書き換えません。

古い記録に確認時刻がない場合は未記録として表示します。モデルの待機理由など、保存されていない処理段階は推測しません。実行側の詳細に残るツール実行・出力・失敗と、指示側の照会結果を対応するタスクIDで照合してください。

## Markdownで保存

1. **MCP指示** または **MCP実行** で対象の行を選択します。
2. **Markdownで保存** を押し、保存先と `.md` のファイル名を選択します。
3. 画面の保存完了表示で保存先を確認します。キャンセルした場合はファイルを作りません。

保存するのは、保存操作を開始した時点の対象タスクのスナップショットです。保存先を選択中に処理が進んでも、別のタスクの内容に置き換わりません。識別情報・状態・取得済み結果と、その端末に残っている対象の履歴をUTF-8で書き出します。大きな履歴が表示・出力の上限に達した場合は、省略があることを明示します。未取得の遠隔ログは含みません。

保存済みの旧配信プロファイルがある場合だけ、履歴画面の **旧配信設定の管理** から従来の配信を管理できます。Hub経由の新しい受付は、端末連携から設定してください。

## Hubから参照する

Hub管理者は、Hubの **MCP履歴** で登録端末を選び、**MCP指示** または **MCP実行** の一覧と詳細を取得できます。Desktopが既存の認証済みHub接続で照会を受け取り、指定されたローカル履歴だけを返します。端末側に新しい待受ポート、証明書ファイル、接続コードを設定する必要はありません。受付OFFでも、Hubとの接続が有効なら履歴を返せます。

Hubは取得日時付きのスナップショットを表示します。切断・期限切れ・旧版Desktopの場合は新しく取得できず、過去に取得した内容を現在の状態として表示しません。Hubでの参照はタスクの再実行や権限変更を行いません。詳細の転送上限に達した場合は省略を表示するため、詳しい調査には対象DesktopでMarkdownを保存してください。

この機能は対応版のHubとDesktopの両方が必要です。更新前のDesktopへ設定を追加して有効にする機能ではありません。
