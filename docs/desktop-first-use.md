# Desktopを使い始める

この案内は現在の開発版の初回画面について説明します。配布済みの旧版とは画面が異なる場合があります。

初回は使い方を選びます。後から別の使い方も追加できます。

| 使い方 | 準備するもの |
| --- | --- |
| 自分のPCで使う | 利用するAIの接続先。会話だけなら作業フォルダーは不要です。 |
| チームに参加する | 管理者から受け取った接続ファイルと本人向け案内。操作だけなら、このPCのモデル・作業フォルダー・実行許可は不要です。 |
| チーム環境を用意する | Hubを含む管理者向け配布物。管理画面から利用者・プロジェクト・接続・実行PCを準備します。 |

## 個人で使う

「自分のPCで使う」から、AIの接続先、モデル、保存内容を確認します。接続先は同じPCでも、到達可能な別のPCでも構いません。AIがまだない場合は、AI環境の担当者にURL・モデル・接続方式を確認してください。moyAIがAIサーバーを自動インストール・起動することはありません。

「モデル一覧を読み込む」で接続先のモデルを取得します。一覧を取得できない場合は、モデルIDを直接入力して保存できます。保存後に短い依頼を送り、AIの回答を受け取れるか試してください。

保存前にツール操作の承認方法を選びます。追加ツールは後から設定できます。保存後はチャットで会話を始め、既存ファイルを扱いたいときに作業フォルダーを選択します。

全項目を順に確認する場合は最初の画面の「すべての設定を確認」を使えます。「以前の設定ファイルを使う」では、TOMLファイルの内容を設定欄に読み込み、最後に保存します。

## チームで使う

「チームに参加する」から接続ファイルを読み込み、このPCの承認を待ちます。承認後、本人のパスワード設定またはログインを済ませると、参加中のプロジェクトが表示されます。利用者の閲覧・依頼の権限と、このPCの利用許可は管理者がそれぞれ設定します。個人で使っていたAIの直接接続設定はそのまま残ります。

初めて利用する人は、管理者から接続ファイルとは別に利用者名と本人設定コードを受け取ります。PCの参加承認後、「本人設定コードで初めて利用する」を開き、案内された利用者名と自分で決めた12文字以上のパスワード、設定コード、確認用パスワードを入力します。設定コードは発行から24時間、一度だけ有効です。応答が途切れた場合は、決めたパスワードで通常ログインを試し、失敗した場合にコードの再発行を依頼してください。従来の利用者は通常のログインを続けて使えます。

Hubのモデルだけをローカル作業で使う場合は、初回画面の詳細「チームのAIだけを、このPCのローカル作業で使う」に従って共通設定を読み込みます。共有仕事への参加とは別の設定です。

この経路で「接続情報は保存済みです。初回設定の完了状態を保存できませんでした」と表示された場合、接続設定は保持されています。設定の保存先を確認して同じ接続ファイルを読み込み直し、初回完了の記録を再試行してください。

「チーム環境を用意する」は同梱Hubの管理画面を起動します。Hubが含まれない配布物の場合は導入案内が表示されます。起動だけでこのPCの仕事の実行許可や業務データの閲覧権限は付与されません。管理側の準備後、このPCも仕事の操作に使うなら「チームに参加する」へ進みます。

## 途中で終了した場合

選んだ使い方は保存されます。初回設定中に完全終了しても、次の起動でその設定画面から再開できます。未保存の入力内容は再入力してください。チームへの参加やログインを済ませていた場合は、保存された情報を使って接続します。

設定ファイルが自動生成されたことだけを、初期設定の完了として扱いません。個人設定を保存した後と、従来から設定済みの利用者には、設定が有効な限り初回案内を強制しません。Hubモデル中継の詳細入口から共通設定を取り込み、検証・保存が完了した場合も初期設定を完了します。通常の設定TOMLを入力に読み込んだだけでは完了しません。
