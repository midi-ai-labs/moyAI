# moyAI v3.0.0-rc.2

## 対象環境

Windows x64向けのリリース候補です。Hubと組み合わせる場合はHub 0.1.0を使います。WebView2とx64 VC++ runtimeが導入済みのPCを対象とし、Setupは前提runtimeをダウンロードしません。配布物とHubの正確な版・commit・hashは添付manifestと組合せ試験の証跡で確認してください。既存の3.0.0と以前の候補の記録は保持します。

## 主な変更

- **長い会話の自動圧縮**: 完了済みの有効履歴を、通常は1回の要約要求で次の作業に必要な文脈へまとめます。前のチェックポイントを置き換え、ツール本文の台帳を累積しません。本文の指示は執筆・調査・監視・データ処理・開発に使えるものとし、出力形式や圧縮率を固定しません。最新の利用者入力とツール呼出し・結果の対応を保持し、入力予算を満たさない要約は採用せず、元の履歴を残します。
- **原文の再取得**: `read_history` で現在の会話の公開履歴を検索し、圧縮前の記録を分割して取得できます。原文は会話の正本に残ります。他の会話、非公開の推論、要求診断は取得対象に含めません。
- **長いツール履歴とChat通信**: トークン予算と要求本文の上限を維持し、固定512メッセージ上限を撤去しました。成功したツール呼出しに必要な非公開の推論継続情報は、実行中のメモリで接続先・モデル・Hub経路へ結び付け、公開履歴や通常の診断へ保存しません。出力を追加しない使用量の終端通知を扱い、本文受信失敗と数値のエラーコードを診断へ保持します。
- **利用上限への再試行**: HTTP 429とSSEの `429` / `rate_limit_exceeded` を、接続確立エラーと同じ有限の再試行枠へ含めます。待機は10秒、20秒、40秒と倍増し、最大300秒です。`model.max_retries` と既存の要求期限の範囲で、出力・推論・ツール呼出し・使用量の受信前だけ同じ要求を再送します。取消で待機を中断し、生成途中の再送や別の接続先への自動切替は行いません。
- **一般文章の作成・編集**: 読者・目的・ジャンルに合わせ、意味、条件、確度、時点を保ち、事実を述べる文章は資料と照合するようAIへ指示します。創作では依頼された自由度や意図的な曖昧さを保ちます。既存の文章指示を独自に具体化したもので、外部Skillの配置や追加設定は不要です。
- **セキュリティレビュー支援**: 組み込みの `moyai-security-review` Skillと `security_review` Toolで、変更後の確認内容、残る指摘、未確認範囲を記録します。宿主は同じsession・turnの正本履歴で確認操作のID、成否、順序を照合します。レビューが未実施・古い・根拠不足の場合は永続feedbackへ表示し、レビューのためだけに追加のモデル呼出しを繰り返しません。詳細は[セキュリティレビュー支援](../security-review.md)を参照してください。
- **ファイル探索の範囲表示**: 一覧、ディレクトリー確認、ディレクトリー内検索に、ignore・hidden・depth条件で見えないファイルがあり得ることを表示します。見つからない結果だけで物理的な不存在を断定せず、正確なパスで読み取って確認できます。

設定と操作は[README](../../README.ja.md)、[Windowsへの導入と更新](../user/windows-setup.md)、[Hubプロジェクト](../shared-work-desktop.md)を参照してください。

## 検証記録と制限

この候補のManual ST、仮想WinA/WinB、配布物の確認は、正確な版・commit・バイナリの識別情報を付けた試験結果と公開時の添付資料で確認してください。再開後の記録先は開発workspaceの `project_sandbox/release-3.0.0-rc2-resume-20261021/RESULTS.md` です。今回の追加機能の単体・全体回帰は `project_sandbox/retry-writing-security-20261021/RESULTS.md`、中断前の記録は `project_sandbox/release-3.0.0-rc2-20261020/RESULTS.md` に分けて保持します。今回の受入判断は、再開後に実施した試験と配布物に対応する証跡に基づきます。以前の成功を今回の受入結果には使いません。

要約と再取得は、必要な事実の完全な保持やモデルの正しい判断を保証しません。過去の記録は現在のファイル内容や新しい操作許可の証明にはなりません。分岐した会話ではコピーされた記録だけを取得できます。生成された文章・コードの品質は、モデルの完了宣言と分けて確認してください。

セキュリティレビューは安全認証や脆弱性の不存在の保証ではありません。`Completed` は作業ターンの終了を示し、安全確認済みを意味しません。確認操作が十分だったかはモデルと利用者が判断し、継続中・別processの変更は履歴順序だけでは検出できません。文章指示も生成品質を保証するものではありません。

仮想WinA/WinBは同じWindows上の隔離環境による試験です。新規PC、物理的に別のPC、LAN・Firewallの受入確認には別の証跡が必要です。通常のDesktop / Runner起動は導入済みsandbox helperを使い、共通helperの導入・更新には管理者承認が必要です。RunnerはWindows利用者のログオン中に動作します。
