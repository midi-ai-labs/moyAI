# moyAI v3.0.6

Windows x64向けの修正版です。WebView2とx64 Visual C++ runtimeが導入済みのPCを対象とし、Hub同梱版にはmoyAI Hub 1.0.4を含みます。

- OneDriveなどのWindows Cloud Files配下の配布物は、ローカルへ取得・照合してから導入します。同期フォルダーからDesktopを開いた場合も、導入済みの同じ内容のDesktopへ引き継ぎます。未導入・更新時は管理者承認が必要です。
- `Setup-moyAI.cmd` の既定をDesktopのみの導入・削除へ変更しました。Hubは管理PCだけで、配布フォルダーの `Setup-Hub.cmd` を実行します。Desktop利用者全員へのHub導入は不要です。
- Runnerの起動準備中にプロセスが終了した場合、パイプの接続エラーだけでなく、その回の起動ログと保存先を表示します。準備完了は読み取り専用のIdentity応答で確認し、仕事の実行要求は再送しません。
- 共有実行登録が残っている端末の接続エラーに、ローカル利用へ戻すための「接続設定をリセット」の案内を追加しました。稼働中の共有登録を無視する変更ではありません。
- アンインストールは、一部の配布ファイルや共通helperが既に削除されていても、残存部分の所有を確認して続けます。削除に必要なスクリプト・導入記録の欠損や改変は引き続き拒否します。
- 保存データの初期化を選んだ場合は、管理者承認・削除可否の確認、元の利用者での初期化、本体削除の順に処理します。初期化失敗時は本体を残します。複数製品のうち先に完了した初期化は取り消せません。
- 旧LocalAppData配置を削除する際、その配置が登録した自動起動・接続ファイルの関連付け・ショートカットも解除します。変更された登録や別配置の登録は保持します。起動中のアプリは強制終了しません。

Windows Cloud Files APIで作成した実際のクラウド属性付きファイルでは、従来の導入処理が拒否すること、新しいローカル準備処理で照合に成功すること、取得不能時は導入を中止することを確認しています。**実際のOneDriveアカウント、組織の同期ポリシー、報告された別PCでの再現確認は行っていません。** そのPCのRunner停止原因をOneDriveだけに断定するものではありません。

通常のローカル利用にはHub参加や共有Runnerは不要です。以前の共有登録が残る場合の解除手順、保存データの扱い、更新手順は[Windowsへの導入と更新](../user/windows-setup.md)を参照してください。
