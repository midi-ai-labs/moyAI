# moyAI v3.0.7

Windows x64向けの設定修正版です。WebView2とx64 Visual C++ runtimeが導入済みのPCを対象とし、Hub同梱版には引き続きmoyAI Hub 1.0.4を含みます。

- Hubへの初回接続時は、未設定のMain・Sub・Approveに、利用可能な「Hubの標準モデル」を設定します。保存済みの個別選択は保持します。標準モデルが利用できない用途では、選択に必要な案内を表示します。
- モデルの選択を変更して元へ戻した後、Hubへ再接続すると、次の変更で「モデル選択を保存」が有効にならない問題を修正しました。
- Approveのモデルを保存した直後に「未設定のためMainを使用」という古い案内が残る問題を修正しました。
- MainとApproveを同じ値へ同時に変更した場合も、明示したApproveの設定を独立して保持します。ApproveのURLもMain・Subと同じ条件で検証します。
- 接続先URLや接続方式の変更時に、同じ追加ヘッダーを明示的に再入力しても消えてしまう問題を修正しました。入力を省略した秘密情報を、新しい接続先へ自動で引き継ぐ変更ではありません。
- GUI監査一覧を現行の公開操作183件・189ケースへ更新し、一覧の不足を検出する検査を追加しました。共通設定・初回設定の53項目と、チャット個別設定6項目について、保存・再表示・再起動後の復元を実Tauri画面で確認しました。

監査一覧にある全機能の全状態を実操作済みとするものではありません。IME・別DPI・物理別PC・すべてのOSファイル選択画面や実行中状態の組合せは今回の確認範囲外です。確認方法と未確認条件は[GUI監査一覧](../../tests/desktop_e2e/MANUAL_GUI_COVERAGE.md)を参照してください。

ZIP全体を展開し、`Setup-moyAI.cmd` で更新してください。Desktop利用者全員にHubを導入する必要はありません。Hubは管理PCでのみ `Setup-Hub.cmd` を実行します。更新手順と保存先は[Windowsへの導入と更新](../user/windows-setup.md)を参照してください。
