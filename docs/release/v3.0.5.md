# moyAI v3.0.5

Windows x64向けの修正版です。Desktop配布物に含まれるWindowsコマンドファイルをCRLF形式で出力します。同梱するHubの `Start-Hub.cmd` が、一部のWindows環境で正しく解釈されず起動できない問題に対応します。DesktopのSetup・起動・アンインストール用コマンドファイルにも同じ形式を適用します。Hub同梱版にはmoyAI Hub 1.0.2を含みます。

従来の導入先、保存先、更新と初期化の手順は[3.0.4リリースノート](https://github.com/midi-ai-labs/moyAI/releases/tag/v3.0.4)と[Windowsへの導入と更新](https://github.com/midi-ai-labs/moyAI/blob/v3.0.5/docs/user/windows-setup.md)を参照してください。WebView2とx64 Visual C++ runtimeが導入済みのPC向けです。

## 検証状況

3.0.4に同梱されたLF形式のHub起動スクリプトは、Windows上でコマンドの断片が誤って実行されることを確認しました。同じ内容でCRLFにした比較用スクリプトは正常終了しました。利用者の指定により、**3.0.5配布物の実動作確認は行っていません。** 以前の版の動作確認を、この版の確認結果として扱いません。
