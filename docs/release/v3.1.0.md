# moyAI v3.1.0

moyAI Desktop v3.1.0 LYNX を Windows x64 向けに公開します。

- 長い会話を開き直した際の履歴表示と、コマンドパレットから入力欄へ戻る際の操作を修正しました。回答の生成中に同じ段落へ文章が追記されても、選択したテキストを保持します。
- 会話内のMarkdown表と、長い会話の履歴を圧縮した際の通知を修正しました。
- Hubで端末の参加許可が取り消されると、Desktopは共有会話の履歴と操作を閉じ、理由と再申請の手順を表示します。
- 文章指示に、数値の境界値を含むかどうかと、複数の条件のうち一つで足りるか、すべて必要かを原文どおりに保つよう明記しました。[yomiyasu v3.2.0](https://github.com/nanaism/yomiyasu/releases/tag/v3.2.0) の編集原則を参考にしています。

ZIP全体を展開して `Setup-moyAI.cmd` を実行してください。WebView2とx64 Visual C++ランタイムが必要です。複数PCで共有する場合は、管理用PCに [moyAI Hub 1.1.0](https://github.com/midi-ai-labs/moyAI-Hub/releases/tag/v1.1.0) を導入してください。

この版の追加検証は、文章指示の自動テストと配布物の照合に絞りました。3.1.0での手動GUI試験と実LLM試験は省略しています。結果はリリースページの `RELEASE_VERIFICATION.md` に記載しています。
