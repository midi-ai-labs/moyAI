# moyAI v3.0.4

Windows x64向けの修正版です。接続リセット後に残った共有実行登録が、ローカルプロジェクトやチャットの依頼を止める問題を修正しました。保存データを初期化するcleanupには、日本語の確認・取消・結果表示を加えました。moyAI Hub 1.0.0と組み合わせて使います。

## 共有実行登録の解除

従来版では、接続をリセットして古い資格を退役させても、PC側の共有実行登録が残ることがありました。通常の依頼がその古いRunnerを要求し、MCPが無効でも「このPCに登録された共有実行機能に接続できません」と表示して実行前に止まっていました。

接続リセットでは、対象のRunnerの終了と共有仕事の清算を確認してから登録を解除します。従来版が残した退役済み登録は、Desktopの起動時と通常の依頼を受け付ける前にも照合します。現在使っている登録や別の構成の登録は解除しません。停止・清算を確認できない場合は登録とデータを保持し、確認が必要な状態を表示します。

## cleanupと旧モジュールの違い

`app/maintenance/moyai-cleanup.exe` は、moyAIの保存データを初期化する保守用です。従来3.xのダブルクリックは対象の表示だけで、削除していませんでした。3.0.4では日本語で削除対象を確認し、「はい」で初期化、「いいえ」で取消を行います。結果も日本語で表示します。`--preview` は引き続き対象の確認だけを行い、CLIでは `--reset-user-data --confirm-delete` の両方で確認画面なしの初期化を指定できます。

初期化するとDesktop設定、本人資格、Desktop側のHub接続情報、会話履歴、保存した結果を削除し、停止・清算を確認したこの利用者の共有実行登録も解除します。すべてのDesktop・CLI・Runner・保持中のアプリを終了して実行してください。稼働中や共有実行の状態が不明な場合は、保存データを削除せず中止します。

cleanupは導入済みの実行ファイルを削除しません。Hub本体とHub側の保存データ、実際のプロジェクト作業フォルダーも保持します。次の操作とは用途が異なります。

| 操作 | 対象 |
| --- | --- |
| `moyai-cleanup` | 設定・資格・履歴等の保存データを初期化。実行ファイルは保持。 |
| `Setup-moyAI.cmd -Uninstall` | 配布時と内容が一致する導入ファイルと対応する登録を削除。変更・追加されたファイルと保存データ、PC共通helperは保持。 |
| 更新時の `moyAI.previous-*` の整理 | 新版導入後に残した旧モジュールの退避先を、必要なファイルがないことを確認して削除。現用の導入先やAppDataは対象外。 |

通常の更新・再接続・アンインストールに、保存データの初期化は必要ありません。詳しくは[Windowsへの導入と更新](../user/windows-setup.md)を参照してください。

## 更新と動作条件

仕事を終了し、新しいZIPを既存の導入先の外へ展開して `Setup-moyAI.cmd` を通常権限で実行してください。共通sandbox helperの更新が必要な場合は、別画面で管理者承認を行います。アプリとhelperは同じ配布物から更新します。Setupによる更新自体は、設定・履歴・作業フォルダーを初期化しません。

このWindows配布物はWebView2とx64 Visual C++ runtimeが導入済みのPC向けで、Setupは不足物をダウンロードしません。[3.0.3](https://github.com/midi-ai-labs/moyAI/releases/tag/v3.0.3)の初期画面描画の確認と起動失敗時の診断案内も引き継ぎます。

Windows 10 2016 LTSBで報告された起動失敗の原因は未確定で、このOSでの実機確認は未実施です。ADアカウントの制限付き実行には、ドメイン参加、ドメインコントローラーへの接続・名前解決、グループ所属の読取りが必要です。AD環境からHubを使った動作報告はありますが、AD tokenとグループに対するアクセス拒否の専用試験は未確認です。Microsoft Entra IDだけのアカウントは未対応です。新規PCの前提ランタイム導入や、物理別PC・LAN・Firewallの受入も、この開発PC上の試験とは別に確認が必要です。

## 検証状況

修正・診断・対象試験と実GUIの記録は、開発workspaceの `project_sandbox/local-submit-diagnosis-20261025/RESULTS.md` にあります。debug候補と正式配布物の結果は、それぞれの識別情報に対応付けて記録します。実施範囲と未確認の条件は、版・commit・バイナリ・ZIPの識別情報を持つ配布検証記録を参照してください。
