# moyAI v3.0.4

Windows x64向けの修正版です。接続リセット後に残った共有実行登録が、ローカルプロジェクトやチャットの依頼を止める問題を修正しました。DesktopとHubの実行ファイルはProgram Files配下、利用者データは共通rootの製品別フォルダーへ揃え、初期化ツールも分けました。moyAI Hub 1.0.1と組み合わせて使います。

## 導入先と保存先

Setupは通常権限で開始し、管理者承認を受けた処理が `%ProgramFiles%\moyAI\Desktop` と `%ProgramFiles%\moyAI\Hub` に実行物を配置します。Hub単体版でも同じHub導入先を使います。通常起動、設定、履歴、ショートカットは元のWindows利用者が所有し、HubをSYSTEMサービスとして起動する変更はありません。

保存データは `%LOCALAPPDATA%\midi-ai-labs\moyai-data\desktop` と兄弟の `hub` に置きます。Desktopは `config`・`data`・`cache` に分かれます。従来の既定保存先は停止状態を確認して移行し、新旧双方にデータがある場合は自動統合しません。移行後や初期化後に旧保存先から履歴・資格を再取込みしません。独自のconfig/data-dir指定と、実際の作業フォルダーは維持します。

DesktopとHubは別々に更新・削除できます。導入記録に一致する旧モジュールは整理し、変更・追加されたファイルや所有を確認できない旧配置は残して場所と理由を表示します。

## 共有実行登録の解除

従来版では、接続をリセットして古い資格を退役させても、PC側の共有実行登録が残ることがありました。通常の依頼がその古いRunnerを要求し、MCPが無効でも「このPCに登録された共有実行機能に接続できません」と表示して実行前に止まっていました。

接続リセットでは、対象のRunnerの終了と共有仕事の清算を確認してから登録を解除します。従来版が残した退役済み登録は、Desktopの起動時と通常の依頼を受け付ける前にも照合します。現在使っている登録や別の構成の登録は解除しません。停止・清算を確認できない場合は登録とデータを保持し、確認が必要な状態を表示します。

## cleanupと旧モジュールの違い

`Desktop/app/maintenance/moyai-cleanup-desktop.exe` は、Desktopの保存データを初期化する保守用です。従来3.xのダブルクリックは対象の表示だけで、削除していませんでした。3.0.4では日本語で削除対象を確認し、「はい」で初期化、「いいえ」で取消を行います。結果を表示してキー入力を待ち、削除失敗や部分完了を正常完了とは表示しません。`--preview` は引き続き対象の確認だけを行い、CLIでは `--reset-user-data --confirm-delete` の両方で確認画面なしの初期化を指定できます。

初期化するとDesktop設定、本人資格、Desktop側のHub接続情報、会話履歴、保存した結果を削除し、停止・清算を確認したこの利用者の共有実行登録も解除します。すべてのDesktop・CLI・Runner・保持中のアプリを終了して実行してください。稼働中や共有実行の状態が不明な場合は、保存データを削除せず中止します。

Hubは `Hub/moyai-cleanup-hub.exe` で別に初期化します。端末登録と共有会話を削除するため、参加済みPCは再参加が必要です。Hub・Gatewayと関連する仕事を停止してから使います。

各cleanupは他方の保存データ、導入済みの実行ファイル、実際のプロジェクト作業フォルダーを削除しません。次の操作とは用途が異なります。

| 操作 | 対象 |
| --- | --- |
| `moyai-cleanup-desktop`（旧名 `moyai-cleanup` も同じ範囲） | Desktopの設定・資格・履歴・キャッシュと対応する共有登録を初期化。 |
| `moyai-cleanup-hub` | Hubの設定・端末登録・共有会話などを初期化。 |
| `Setup-moyAI.cmd -Uninstall -Components Desktop` / `-Components Hub` | 対象製品の導入記録に一致する実行物と対応する登録を削除。保存データと他方の製品は既定で保持。 |
| `-Uninstall -Interactive` | 確認画面で対象と保存データ初期化・PC共通helperの削除を選択。 |

通常の更新・再接続・アンインストールに、保存データの初期化は必要ありません。詳しくは[Windowsへの導入と更新](../user/windows-setup.md)を参照してください。

## 更新と動作条件

仕事を終了し、新しいZIPを既存の導入先の外へ展開して `Setup-moyAI.cmd` を通常権限で実行してください。別画面で管理者承認し、選択した製品を更新します。Desktopと共通helperは同じ配布物から更新します。Setupによる更新自体は、設定・履歴・作業フォルダーを初期化しません。Hubの初期ポートは固定の9080で、Setupの `-WebPort` で明示変更できます。指定しなければ保存済み設定を保持します。

このWindows配布物はWebView2とx64 Visual C++ runtimeが導入済みのPC向けで、Setupは不足物をダウンロードしません。[3.0.3](https://github.com/midi-ai-labs/moyAI/releases/tag/v3.0.3)の初期画面描画の確認と起動失敗時の診断案内も引き継ぎます。

Windows 10 2016 LTSBで報告された起動失敗の原因は未確定で、このOSでの実機確認は未実施です。ADアカウントの制限付き実行には、ドメイン参加、ドメインコントローラーへの接続・名前解決、グループ所属の読取りが必要です。AD環境からHubを使った動作報告はありますが、AD tokenとグループに対するアクセス拒否の専用試験は未確認です。Microsoft Entra IDだけのアカウントは未対応です。新規PCの前提ランタイム導入や、物理別PC・LAN・Firewallの受入も、この開発PC上の試験とは別に確認が必要です。
