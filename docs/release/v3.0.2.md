# moyAI v3.0.2

Windows x64向けの修正版です。HubにつないだDesktopで、待機中のチャット画面が繰り返し再描画される問題を修正しました。引き続きmoyAI Hub 0.1.0と組み合わせて使います。

## 修正内容

表示内容が変わっていない定期更新では、チャット画面の表示を維持するようにしました。同じ新規チャットの下書きも、内容が変わらない更新ではカーソル位置とスクロール位置を維持します。実際に状態や内容が変わった場合の更新は引き続き反映します。

## 引き継ぐ対応と動作条件

[3.0.1](https://github.com/midi-ai-labs/moyAI/releases/tag/v3.0.1)のADドメインアカウント対応を引き継ぎます。Windows x64と、導入済みのWebView2・x64 Visual C++ runtimeが必要です。この配布物のSetupは前提runtimeをダウンロードしません。

ADアカウントで制限付きコマンドを実行するには、PCのADドメイン参加、ドメインコントローラーへの接続・名前解決、共通helperによる利用者のグループ所属の読取りが必要です。Microsoft Entra IDだけのアカウントは未対応です。認証や制限付き実行の失敗を、フルアクセスでの自動再実行へ切り替えません。

AD環境からHubを使った動作報告はありますが、ADのtokenとグループに対するアクセス拒否を確かめる専用試験は未確認です。今回の再描画修正の検証とは分けて扱います。

## 更新

Desktop・CLI・Runnerの仕事を終了してから、新しいZIPを既存の導入先の外へ展開し、`Setup-moyAI.cmd` を通常権限で実行してください。共通helperの更新が必要な場合は、別画面で管理者承認を行います。アプリと共通helperは同じ配布物で更新します。設定・履歴・成果を初期化する必要はありません。詳しくは[Windowsへの導入と更新](../user/windows-setup.md)を参照してください。

検証結果は開発workspaceの `project_sandbox/release-3.0.2-redraw-20261021/RESULTS.md` と、版・commit・バイナリの識別情報を付けた配布証跡へ記録します。
