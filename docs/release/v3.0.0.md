# moyAI v3.0.0

## LYNX 暫定ビルド

2026-09-06。別のWindows x64端末でDesktopを確認するための非公開の暫定ビルドです。正式リリースではなく、未commitの開発変更を含みます。配布物のmanifestに実際のsourceとbuild identityを記録します。

- Desktopの配色・余白・情報の強弱をLYNXとして見直しました。
- 同一PCのmoyAI Hubとの接続、モデル選択、Main / Sideの推論連携を実装しています。HubアプリはこのDesktop配布物に含みません。
- 「MCPを配信」は読み取り6種と、明示的なエージェント受付のProject/tempを選べます。既定は認証付きloopbackで、具体的なIPとTLS証明書を指定するHTTPS配信、委任先端末の登録、受入ジョブの個別停止を追加しています。操作と制約は [MCP配信](../design/mcp-publish-foundation.md) と [複数端末への委任](../design/remote-agent-delegation.md) を参照してください。
- MCP画面の選択欄と、ウィンドウ復帰後に配信操作が更新されない不具合を修正しました。

## 別端末での起動

ZIPをフォルダーごと展開し、`bin/moyai-desktop.exe`を起動してください。`ui/desktop-web/dist/`や`logo/`を含む配置を維持してください。RustやNode.jsの開発環境は不要です。WindowsのWebView2 Runtimeが必要です。

Desktopだけで試す場合は、初期設定で接続先LLMサーバーのURLとモデルを設定します。別のPCでホストするモデルには、そのPCへ到達できるIPアドレスを指定してください。`127.0.0.1`はDesktopを起動した端末自身です。

同梱の`moyai.exe`はCLI / TUI用、`moyai-cleanup.exe`はmoyAIの保存データを初期化する保守用です。通常のDesktop起動には使いません。

## 確認範囲

Rust全体試験、Desktop frontend試験、Windows実GUIの検証は変更した段階ごとに行っています。最終ソースと配布物自体の検証結果は、この暫定ビルドに対応するRESULTSとmanifestを参照してください。

Desktop MCPは同一PCで委任側・受入側のcanonical sessionを分け、実GUIからのTLS設定・端末接続、実oMLXのCPU調査往復、実shellを使うジョブの個別停止を確認しました。最終表示修正も実GUIで確認済みで、物理Windows 2台での受入は未実施です。これは正式リリースや、配布物ごとの検証完了を意味しません。

Hub自身のLAN接続、接続者別pairing、親タスクからの遠隔一括停止、対話承認、Hub worker routing、成果物転送、N台受入は後続です。readモードへ書き込みtoolを公開したものではありません。このZIPは全機能・全OS・全MCP clientの受入完了を示すものではありません。
