# moyAI v3.0.0

## 対象環境と組合せ

Desktop 3.0.0とHub 0.1.0（commit `f437c4fe0191e69f0ff7f0affa16eb191db305f3`）を組み合わせます。対象はWebView2とx64 VC++ runtimeが導入済みのWindows x64 PCです。Setupは前提runtimeをダウンロードしません。

## 主な変更

- HubへのPC参加とプロジェクト単位の許可、通常のチャットからの別PCへの依頼・承認・実行・成果の受渡し。
- メイン・サイド・承認用AIの独立した接続設定と、画面とは独立して仕事を続けるWindows Runner。
- 初回導入・更新・削除時だけ管理者承認を使う固定Windows sandbox serviceと、許可済みworkspace / TEMPでのPython・pytest一時フォルダーの読み書き。通常のDesktop / Runner起動は管理者承認を求めません。
- 長い保存会話の再開における履歴処理・実行権更新と、Side Chatでの元の依頼・過去の要約・各作業の最後の回答・最近の実行結果の予算内選択。
- Doclingの文書処理承認の清算、通常の画像分析のLLMへの受渡し。

詳しい実装範囲は[確定commitのRCリリースノート](https://github.com/midi-ai-labs/moyAI/blob/83a498dd5afc2219e5ce068a608bf8e4a158f139/docs/release/v3.0.0-rc.1.md#現行の変更)、利用手順は[Windowsへの導入と更新](../user/windows-setup.md)と[Hubプロジェクト](../shared-work-desktop.md)を参照してください。RCノートは候補版の当時の試験記録です。

## 検証範囲と記録

RCの元となる実装ではManual ST Case1〜7と復元試験を実施し、同じWindows PC上の仮想WinA/WinBで固定応答・実LLMによる実行・成果受渡し・終了処理の自動確認を実施しました。生成コードの評価NG、Side Chatの回答精度不足、人手確認が残る `manual_pending` は元の記録を保持しており、全回答の合格や正式3.0.0配布物の受入完了を意味しません。過去の実施範囲と証拠の場所は[確定commitのRCの確認済み範囲](https://github.com/midi-ai-labs/moyAI/blob/83a498dd5afc2219e5ce068a608bf8e4a158f139/docs/release/v3.0.0-rc.1.md#確認済みの範囲)を参照してください。

正式3.0.0の確定commitに対応する全体check・再ビルド、ZIP / manifest / SHA256の照合、導入・更新後の実GUI、正式Desktop / Runner / Hubの基本動作と通常終了、作業で使ったprocessと保存境界の確認結果は、開発workspaceの `project_sandbox/release-3.0.0-20261016/RESULTS.md` に記録します。実施済み・未実施・NGの区別と配布物の識別情報は同記録で確認し、RCや旧版の成功と混同しないでください。

固定sandbox serviceへの変更と追加検証は `project_sandbox/windows-sandbox-installed-service-20261016/RESULTS.md` に記録します。以前の候補配布物の成功を、この変更後の配布物の成功として扱いません。

新規Windows PCへの導入、物理別PC・LAN・Firewall、旧公開版からの更新互換性は、同じPC上の自動試験だけでは確認できません。未実施の範囲を成功扱いにしません。

## 利用上の制限

- モデルの回答・生成コードには誤りが残ります。回答の説明と生成物の試験結果を分けて確認してください。
- 各PCのフォルダー全体は自動同期しません。停止や発言の編集は、作成済みファイルや起動済みアプリを巻き戻しません。
- 停止要求の受付と実プロセスの停止確認は別です。停止を確認できない枠を自動で再利用しません。
- Windowsの実行補助機能はlocal SAM accountを対象とします。補助serviceはLocalSystemで必要時に動き、Runner自体は利用者のログオン中に通常権限で動作します。Runner自体のOSサービス運用とHubルートCAの全端末への自動入替は未対応です。

DesktopとHubを対応する組合せへ更新してください。配布物の版・commit・ファイル構成は添付manifestを正とし、開発環境の接続先や資格情報を配布設定へ固定しません。
