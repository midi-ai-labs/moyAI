# moyAI v3.0.8

Windowsの再導入・cleanupを修正し、DesktopとHubの配布物を分離しました。

- Setupは、正規の共通サービス登録だけが残った状態、サービス登録だけが消えた状態、一部ファイル欠損、空の配置先、更新途中の無効化から再導入できます。
- Desktop・CLI・Runnerの終了後も共通サービスが稼働していれば、Setupが通常停止してから更新・削除します。停止失敗時は旧ファイルを保持します。実行中のアプリは強制終了しません。
- Desktop本体の配置・検証やサービスの登録更新に失敗した場合は、旧Desktopと旧サービスの配置・登録を戻します。置換に成功した旧モジュールは整理し、追加・変更されたファイルは保持して場所を表示します。
- Desktop用cleanupは、停止を確認した本人の対象profileについて、対応する実行記録がない古い共有実行登録も整理できます。未清算・破損した残存記録や稼働中のownerは引き続き削除を止めます。
- DesktopのZIPにはHub本体・Hub用Setup・Hub用cleanupを含めません。Hubを管理するPCには[Hub単体版](https://github.com/midi-ai-labs/moyAI-Hub/releases/latest)を導入してください。DesktopのHub接続機能と旧同梱版の導入記録の互換性は保持します。

通常更新では設定・資格・接続情報・会話履歴・作業フォルダーを保持します。保存データを初期化する場合だけcleanupを実行します。[Windows導入手順](../user/windows-setup.md)を参照してください。

Windows x64向けで、WebView2とVisual C++ x64 runtimeの事前導入が必要です。Setupは不足するruntimeをダウンロードしません。

検証結果は配布物内の `docs/release/manual-gui-st-results.md` に記録します。実際に障害が起きた他の利用者のPC、組織固有のACL・OneDrive同期環境は、手元の隔離試験とは区別します。権限や所有を確認できないサービス・ファイルを無条件に削除する機能はありません。
